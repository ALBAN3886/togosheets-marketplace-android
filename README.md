# TogoSheets Marketplace Android

App Android **coquille WebView** pour TogoSheets Marketplace — propulsé par AET Technology.

⚠️ Ce dépôt ne contient **aucun code web** (plus d'`index.html` local depuis le
nettoyage du 2026) : l'app charge directement en ligne
`https://alban3886.github.io/togosheets-pro/public.html`. Le vrai code source
vit uniquement dans le dépôt **togosheets-pro**, fichier `public.html`.

## 🚀 Comment générer l'APK
1. GitHub Actions génère l'APK automatiquement à chaque push sur `main`.
2. Allez dans **Actions** (ou **Releases** si configuré) pour télécharger l'APK.

## 📱 Application
- **Nom** : TogoSheets Marketplace
- **Package** : com.aet.togosheets.marketplace
- **Min SDK** : Android 5.0 (API 21)
